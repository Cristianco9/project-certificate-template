# Plantilla de certificado escolar - HTML y CSS Responsivo

Esta plantilla representa un **generador de certificados académicos** desarrollado
con  **HTML5** y **CSS3**, diseñada como un recurso educativo en el desarrollo de
interfaces web modernas, limpias y adaptables. Puede integrarse fácilmente como
parte de un sistema web más grande, complementando módulos como el de dashboard
o autenticación.

## 📌 Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript** (para funcionalidad de impresión)

## 🎯 Características principales

- 💎 **Diseño moderno y estilizado**, centrado en la presentación clara del 
certificado académico.
- 📱 **Diseño responsivo**, adaptado automáticamente a:
  - Teléfonos móviles 📱
  - Tablets 📟
  - Computadores de escritorio 🖥
- 🧩 **Diseño estructurado** que organiza visualmente:
  - Menú de aplicación
  - Escudos institucionales
  - Información del estudiante
  - Notas de asignaturas y concepto de desempeño
  - Detalles del año académico y sede
  - Pié de página
- ⚙️ **Animaciones suaves**:
  - Aparición de contenido con `fadeIn`
  - Efecto hover en botones para mejor interacción

## 🧭 Secciones del Certificado

- **Encabezado**:

  - Escudo de Colombia y escudo de la institución educativa.
  - Nombre de la institución y ubicación.

- **Cuerpo del certificado**:

  - Título "CERTIFICA" para destacar el propósito del documento.
  - Información sobre el estudiante:
    - Nombre completo.
    - Grado cursado.
    - Sede donde realizó los estudios.
  - Tabla con las asignaturas, horas de clase y conceptos de desempeño (Excelente, Bueno).

- **Pie de página**:
  - Información sobre la promoción al siguiente grado.
  - Fecha de emisión del certificado.

- **Botón de impresión**:
  - Permite imprimir el certificado con el formato actual.

## 🚀 ¿Cómo utilizar esta plantilla?

1. Clona este repositorio en tu equipo:
   ```bash
   git clone https://github.com/iensc-software-sena/project-certificate-template.git
   ```
2. Accede al directorio del proyecto:
   ```bash
   cd project-certificate-template
   ```
3. Abre el editor de código VSC:
   ```bash
   code .
   ```

## 📝 Personalización recomendada

- Reemplaza las imágenes de los escudos con las imágenes de tu institución.
- Ajusta la información de la institución educativa y los datos del estudiante.
- Personaliza las asignaturas y notas según los datos de tu sistema educativo.
- Modifica el esquema de colores si deseas adaptarlo a tu branding.
